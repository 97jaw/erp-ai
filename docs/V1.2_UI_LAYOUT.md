# V1.2 UI LAYOUT — Unique Floating Design

> **The Big Idea:** A spatial, transforming interface inspired by macOS Spotlight, VS Code tabs, and v0.dev — where every element moves and adapts to user intent.

> **Read first:** `PROJECT_CONTEXT.md`, `V1.2_VISION.md`

---

## CONCEPT SUMMARY

```
✦ NO traditional header / footer / sidebar by default
✦ Quick links float center on idle, slide to LEFT when typing
✦ Input transforms like macOS Spotlight (Cmd+Space feel)
✦ Submitted queries save as TABS on RIGHT sidebar (VS Code style)
✦ Middle area = ONE active response at a time
✦ Hover any tab → micro-preview popup
✦ Click tab → swap response in middle area
✦ Splash = full-screen feature showcase (not a popup)
```

---

# 1. THE FOUR LAYOUT STATES

The interface has 4 distinct states that flow into each other:

```
STATE A → IDLE / WELCOME
   Quick links centered, no input visible
   Big welcome message + feature showcase

STATE B → TYPING ACTIVE
   User clicks input area or hits "/"
   Input expands like macOS Spotlight
   Quick links animate to LEFT sidebar

STATE C → RESPONSE GENERATING
   Input disappears
   Skeleton/placeholder appears in middle
   Loading animations everywhere
   New tab appears in RIGHT sidebar

STATE D → RESPONSE VIEWING
   Full response in middle area
   RIGHT sidebar has tab for each past query
   Hover tab → preview
   LEFT sidebar still has quick links (collapsed)
```

## 2.2 Headline Typography

```
Title:
  Font: Custom display font (e.g., "Cal Sans" or "Tan Mon Cheri")
  Size: 64-80px on desktop, 40px on mobile
  Weight: Bold
  Animation on load:
    - Each letter fades in from below (50ms stagger)
    - Subtle gold gradient sweep across (one-time, 1.5s)
    - Letter spacing animates from 200% → normal

Subtitle:
  Font: Light weight, 24px
  Color: muted (60% opacity)
  Animation: Fades in 300ms after title
```

## 2.3 Feature Cards (6 cards in 3x2 grid)

Each card is a glassmorphic tile showing one capability:

```
Card Specs:
  Size: 200x200px
  Background: theme glass
  Border: gradient gold (subtle)
  Padding: 24px
  
Content:
  Icon: 48px animated (Lottie or SVG)
  Title: 16px bold
  Subtitle: 14px muted (single line)
  
Hover:
  Card lifts 8px
  Glow intensifies
  Icon plays animation
  Background gradient shifts
  Click reveals demo

Click behavior:
  Card flips/morphs into actual demo
  Shows 3-second visualization of that feature
  Returns to card on second click
```

# 3. STATE B — TYPING ACTIVE (Spotlight Mode)

## 3.1 The Transformation Animation

When user presses "/" or clicks input area:

```
T+0ms:   Welcome text fades out (200ms)
T+100ms: Feature cards start moving:
         - All 6 cards slide LEFT simultaneously
         - They organize into a vertical stack
         - Each card shrinks to 64x64px (icon-only)
         - Final position: left edge, 16px from left
T+300ms: Spotlight input appears center:
         - Starts small (300px wide)
         - Expands to 700px wide
         - Background blurs more intensely
         - Subtle scale-in animation
T+500ms: Input is ready, focused, cursor blinking
```

## 3.3 Spotlight Input Design

```
Dimensions: 700px width, ~80px height (expands as text grows)
Style:
  Background: Heavy glass blur (40px backdrop-filter)
  Border: 2px gradient (gold→cyan)
  Border-radius: 16px
  Shadow: Large soft drop shadow

  [🎤 mic icon]  [text input field]  [→ send icon]

  Text: 24px font, light weight, color white/dark
  Placeholder: "Type your question or speak..."
  Cursor: Tall (24px), gold color, blinks

  Mic icon pulses on hover
  Send button appears only when text exists
```

## 3.6 Backspace Behavior

```
When user backspaces ALL text (input empty):
  - Wait 200ms (avoid jitter)
  - If still empty:

    * Smooth animation back to STATE A
    * Quick links slide back to center positions
    * Welcome text fades back in
```

# 6. ANIMATION SPECIFICATIONS

## 6.1 Welcome → Typing (State A → B)

```
Duration: 600ms total

Welcome elements fade-out:
  Welcome title: opacity 1 → 0 (200ms)
  Feature cards: scale 1 → 0.8, opacity 1 → 0 (250ms staggered 30ms each)
  Subtitle: opacity 1 → 0 (200ms, delay 100ms)

Then:
  Feature cards: move to left sidebar positions (400ms ease-out)
  Spotlight input: scale 0.8 → 1, opacity 0 → 1 (300ms)
```

## 6.2 Typing → Generating (State B → C)

```
Duration: 500ms total

User hits Enter:
  Input: scale 1 → 0.95 (50ms, acknowledgment)
  Input: slides up 200px, opacity → 0 (200ms)
  
Tab materializes:
  Right sidebar: tab appears with scale 0 → 1 + fade
  Other tabs slide down to accommodate

Center area:
  Skeleton appears with fade-in (200ms delay)
  Shimmer animation starts immediately
```

## 6.3 Generating → Viewing (State C → D)

```
Duration: 800ms total

Skeleton transitions to real content:
  Each skeleton element: blur(8px) → blur(0) (300ms)
  Numbers count up from 0 to value (400ms)
  Charts: bars/lines draw themselves (500ms)
  
Suggestions appear:
  Fade up + stagger (100ms each)
  
Tab gains "active" state:
  Gold accent bar slides in from left (200ms)
```

## 6.4 Tab Switching

```
Duration: 350ms

Old response:
  Slide horizontally + fade out (200ms)
  
New response:
  Wait 100ms (avoid overlap)
  Slide in from opposite direction + fade in (250ms)
  
Active tab indicator:
  Gold bar slides between old and new tab (300ms)
```

## 6.5 Backspace All → Back to Idle

```
Duration: 600ms total

User backspaces to empty + 200ms delay:
  Suggestions: fade out (150ms)
  Spotlight input: shrinks back, slight delay (200ms)
  
Quick links return:
  Slide from left sidebar back to center grid positions (400ms ease-out)
  Welcome text fades back in
```

# 10. STATE MANAGEMENT

```typescript
// React Context structure
interface AppState {
  // Layout state
  currentScreen: 'welcome' | 'typing' | 'generating' | 'viewing';
  
  // Query history (tabs)
  queries: Query[];
  activeQueryId: string | null;
  
  // Current generation
  currentGeneration: {
    status: 'idle' | 'thinking' | 'fetching' | 'generating' | 'complete';
    progress: GenerationStep[];
    skeleton: SkeletonType | null;
  };
  
  // UI state
  leftSidebarCollapsed: boolean;
  rightSidebarVisible: boolean;
  theme: 'light' | 'dark';
  
  // Input state
  inputValue: string;
  suggestions: string[];
  isRecording: boolean;
}

interface Query {
  id: string;
  text: string;
  language: 'en' | 'ar';
  response: BotResponse | null;
  timestamp: number;
  vizType: VizType | null;
  pinned: boolean;
}
```

# 11. EDGE CASES

## 11.1 Long Response Text

```
If response text > 1000 chars:
  - Show first 500 chars
  - "Show more" button to expand
  - Tab preview shows first 200 chars
```

## 11.2 Many Tabs (>10)

```
Right sidebar:
  - Auto-scrolls
  - Older tabs auto-archive (collapse to "Earlier today" group)
  - Pinned tabs always visible
  - Max 30 tabs (oldest auto-deleted with warning)
```

## 11.3 Failed Generation

```
If AI fails to generate:
  - Skeleton transforms into error state
  - Friendly error message
  - "Try again" button
  - "Edit query" button
  - Tab is marked with red dot
```

## 11.4 User Navigates Away

```
If user closes/refreshes:
  - All queries saved to localStorage
  - On reload: tabs restore
  - Active query restores
  - Theme preference preserved
```
